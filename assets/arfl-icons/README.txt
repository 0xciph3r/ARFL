ARFL icon pack
svg/       vector sources (mark.svg is the brand mark as supplied)
desktop/   macos (1024 + iconset sizes), windows (png + ico), tray (macOS template images, Windows white glyphs)
mobile/    ios (1024 full bleed, no alpha), android (adaptive foreground, background, monochrome, notification, Play Store)
web/       favicon.svg, favicon.ico, png sizes, apple-touch-icon, manifest icons, head snippet

Tray: "off" is the outline mark, "on" is the filled mark. macOS files are template images (black with alpha), so the system tints them.
Small sizes (16 to 32 px) drop the two eye dots and use a heavier stroke.
